# 장성환 | 풀스택 개발자 포트폴리오 (Developer Portfolio)

> **복잡한 엔터프라이즈 인프라 도메인을 안정적인 소프트웨어로 완결짓는 6년 차 풀스택 개발자 장성환입니다.**  
> B2B 데이터센터 인프라 관리(DCIM) 솔루션의 핵심 모듈(성능 분석, 계통 토폴로지, 작업 관리, SW 품질 안정화)을 요구사항 정의부터 화면/ERD 설계, 백엔드 API, 대규모 데이터 시각화까지 엔드투엔드로 주도해 왔습니다.  
> 안정적인 엔터프라이즈 레거시 환경(Vue 2, Spring, Oracle)과 최신 모던 웹 스택(Vue 3, Vite, Pinia, PWA, Firebase)을 두루 다루며, 최신 AI 생산성 도구를 적극 지휘하여 고속 개발을 주도하는 AI-Native 엔지니어링을 실천하고 있습니다.
